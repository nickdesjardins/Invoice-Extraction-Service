    02 · Model upkeep

    What happens when a free model disappears

    Free models are withdrawn without notice. This service can look after its own chain: when a model stops answering and OpenRouter no longer offers it, the service tests the free models that are on offer with seven sample documents and gives the free place to one that passes. By itself it tests nothing while the chain works.

      04 · How it works

      Five steps between the text and the invoice

      1. Validate the request

        The body must carry 10 to 50,000 characters of text. Anything else is a 422 before a model is called.

      2. Fence the document

        The text is wrapped in document markers, literal markers inside it are defanged, and the prompt declares it untrusted data.

      3. Walk the chain

        Strict JSON-schema output at temperature 0. Any classified failure moves to the next model; two “not an invoice” verdicts stop early.

      4. Validate and normalise

        Pydantic recomputes every line total, maps currency symbols to ISO 4217 and collapses “N/A” to empty.

      5. Report what happened

        Every response names the model that answered, the time it took and whether a fallback was needed.

      How the default chain was chosen

      Free models come and go, so this is a dated snapshot, not a live reading. Each free model on OpenRouter that advertised structured output was sent the documents from the playground above, through this service's own prompt, schema and validation.

        What a caller can rely on

        • Line totals always add up Each one is recomputed as quantity × unit price, never copied from the model.
        • One shape, whichever model answers The same prompt, schema and validators apply to every model in the chain.
        • Errors are sanitised Raw upstream text stays in the server log, keyed by the request id.
        • Failures are attributable A success names the model that answered; a 503 lists every attempt and why it failed, or says that the ceiling on live calls refused the request before any model was called.
